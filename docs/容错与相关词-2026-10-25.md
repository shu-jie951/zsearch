# 容错匹配与相关词 · 2026-10-25

**起因**：老板说「搜索词可能打错或者少打，要容错；要能延伸到更多相关关键词/名称相关的资源」，
并给了一张网盘搜索导航站的截图（全盘搜 / 片库 / 聚盘搜索 / 刀搜盘 / 追新番 … 二十来个站），
让先研究这些站的搜索策略再动手。

---

## 一、从那批站学到了什么

先承认一件事：那二十来个站**绝大多数是同一类东西** —— 夸克/百度分享链接的索引站，
差别只在覆盖的渠道与前端体验，不在"搜索算法"。翻完一圈，可迁移的策略其实就四条：

| 来源（举例） | 策略 | 我们是否借鉴 |
| --- | --- | --- |
| 云铺子 | 关键词模糊匹配 + 类型筛选 | ✅ 本轮做 |
| 橘子盘搜 | 结果自动标注 蓝光/高清/字幕 | 已在 2026-10-24 的意图识别里做了 |
| Fastsoso / 盘库吧 | 自动过滤失效链接 | 已有 `lib/linkCheck.js`（探活），不重复 |
| 追新番 / 各影视站 | 结果页底部「相关搜索」chips | ✅ 本轮做（从标题统计，不是词库） |

没有迁移价值的是那些靠**词库/别名表**的站 —— 需要长期人工维护，且为热门资源优化、
长尾资源照样搜不到。我们选的路是**对查询与标题本身做容错**，冷热通吃。

---

## 二、容错三件套

三把刀各管一种「打偏了」：

| 情况 | 例子 | 机制 | 文件 |
| --- | --- | --- | --- |
| 打错一个字 | `庆余午` → 庆余年 | 标题窗口编辑距离 ≤1 | `lib/fuzzy.js` |
| 少打中间的字 | `庆年` → 庆余年 | 有序子序列覆盖率 | `lib/fuzzy.js` |
| 打拼音/首字母 | `qyn` / `qingyunian` → 庆余年 | **把标题转成拼音再比** | `lib/pinyin.js` |

### 拼音为什么是这个方向

把 `qyn` 还原成中文是多对一 —— 庆余年 / 千与千寻 / 倩女幽魂。猜错就是把用户
送到完全无关的资源上。反过来，把**标题**转成拼音再比对，是确定的：
命中就是命中，不命中也不会猜错。

字表（20775 字 / 403 音节 / 65.8KB）由 `_build_pinyin.js` 在构建期用
pinyin-pro 生成静态文件，运行时零依赖、零启动开销。刻意不加运行时依赖。

### 为什么不做同音字纠错

「庆余念 → 庆余年」这种 IME 选字错误，理论上可以用拼音反查生成同音变体。
但同音候选几十个、组合爆炸，而且没有词频表就排不出「哪个最可能」。
成本（维护字表 + 词频表）与收益（覆盖一种低频错误）不成比例，**没做**。
词尾打错的召回已经由「前缀截断」变体兜住（见下）。

---

## 三、前缀截断 —— 唯一不需要词典的纠错

上游是子串匹配，词尾打错一个字（庆余午），整串必然 0 条。
砍到前两个字（庆余）就绕开了错字，上游照样返回「庆余年…」。

4 字以上的纯中文查询，自动生成两个变体，排在最后兜底：

```
庆余午第二季 → 庆余午(去季集) / 庆余(前缀)
```

扩展预算：最多 3 个变体、每个 12s、**总预算 30s**；主词命中 ≥5 条就不追。

## 四、相关词（"下一步搜什么"）

借鉴各影视站结果页底部的「相关搜索」，但**不用词库** —— 词库会过时，
而且从标题统计出来的词一定是当前这批结果里真的存在的东西。

`lib/related.js`：

1. 标题切出中文片段，统计 2-gram
2. 过滤查询词本身（**按位置重叠过滤**，不只是按内容——
   「考研数学一」里「研数学」这种半个字粘着查询词的垃圾会被挡住）
3. 过滤泛词（合集/下载/资源/更新…）与纯数字
4. 「后一个字投票」向右扩成 3~4 字（得到「庆余年第二季」而不是「余年第」）
5. 按「次数 × 长度权重」排序，取前 8 个

前端在统计行渲染成可点击的 chips（与「试试：」共用胶囊样式）。

## 五、验证

| 项目 | 结果 |
| --- | --- |
| `node _qa_query.js` | **46 / 46**（新增容错 6 条 + 相关词 4 条） |
| `node _verify_search_flow.js` | 23 / 23 |
| `node _verify_results_stub.js` | **15 / 15**（新增「相关词 chips 渲染」） |
| `node _qa_ui_static.js` | 55 / 55 |

实测打分（本地构造标题）：

```
庆余午(错字)  vs 「庆余年 第二季 全集」    →  27 分（命中）
庆余午(错字)  vs 「热门影视合集大全」      →  -8 分（无关）
庆年(少打)    vs 「庆余年 第二季 全集」    →   8 分（弱命中，能浮上来）
qyn          vs 「庆余年 第二季 全集」    →  38 分
qingyunian   vs 「庆余年 第二季 全集」    →  45 分
```
